# 数据定义

除权参考价=(前收盘-每股现金+配股价×配股比例)/(1+送转比例+配股比例)，按登记日判定权益，零碎股单列。

输入字段：record, kind, security, alias, event_date, record_date, ex_date, price, cash, bonus, rights, rights_price, shares, version, reported_cash。可选归属字段：client（客户）、account（证券账户）。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

每行position是投资者在event_date结束时的登记快照；本示例同一证券同一除权日只有一项合并公司行动，不将多个日终快照相加。登记日当天有权益，次日新增持仓无权益。送转与配股产生的新增股份向下取整，零碎股保留。现金按每项行动总额四舍五入到分，再按最大余额分配，记录ID作稳定顺序。无税费及真实交易所连接。

## 账户归属与客户合并

- 持仓的账户由`account`给出，缺省为持仓记录；客户由`client`给出，缺省为账户。同一账户在同一文件内只能归属一个客户，否则整组隔离为`ATTRIBUTION_CONFLICT`。
- 同一账户同一证券同一快照日只能有一条持仓，重复且内容不同的记录隔离为`POSITION_CONFLICT`。
- 权益登记按账户取登记日前最后一笔快照；同一客户多账户各自独立判定权益。
- 交易所按账户登记：每个账户的送转/配股新增股份各自向下取整；现金按行动总额一次四舍五入到分，再在同一行动的各账户间按最大余额分摊。
- 客户合并口径：先按客户合并持仓计算应得总数（新增股份向下取整、现金四舍五入到分），再用最大余额法把客户总数分摊回各账户，账户分摊合计必须等于客户总数。
- 尾差 = 客户合并总数 − 逐账户登记合计；正数表示客户合并后多出的股数/分币，分摊给零碎余数最大的账户，记录ID作稳定顺序。
- 客户层面零碎股不进入账户整数股，单独列示；不四舍五入为客户新增股份。
- 已确认台账只保存账户级分摊结果；客户总数由账户分摊实时汇总。

## 发布状态

| 状态 | 含义 |
|---|---|
| 不可发布 | 存在阻断项：归属冲突、记录不守恒、分摊不闭合，或已确认账户归属被改变且未确认 |
| 待复核 | 内部一致，但尚未复核通过或与已确认结果存在差异 |
| 可发布 | 内部一致、无未确认差异，等待复核动作 |
| 已发布 | 当前批次已复核通过并成为已确认台账 |
