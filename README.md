# 证券除权复权与持仓对账

券商数据校验员使用本工具完成：归一公司行动与成交持仓文件，复算除权因子和股数现金。

## 业务

除权参考价=(前收盘-每股现金+配股价×配股比例)/(1+送转比例+配股比例)，按登记日判定权益，零碎股单列。八个模块：行动接收、证券映射、权益登记、除权因子、持仓重算、现金对账、修订回放、客户合并。模块独立API及页面入口见docs/API.md。样例中包含真实常见脏数据，原因码和原始行号在隔离面板及证据文件中可复核。

同一客户在同一证券开立多个账户时，交易所以账户为单位登记送转与现金，客户服务按客户合并展示。客户合并模块同时给出逐账户登记数、客户合并总数与分摊回各账户的结果，并列出股份/现金尾差落在哪个账户；首次复核通过后形成已确认台账，同批重跑按run_id复用、不重复增加权益，晚到账户归属变更会阻断发布并需逐账户确认。

## 启动与验证

```sh
docker compose up --build -d
docker compose exec -T app pytest -q
docker compose config --quiet
```

打开 http://localhost:18209 。点击“运行样例”，或展开输入区提交CSV。切换八个模块查看计算依据。复核区可通过或退回，同一版本仅允许一次复核；发布区显示客户总数、逐账户差异与当前能否发布。多账户样例见 sample_data/multi_account.csv。证据CSV包含所有阶段与隔离行，批次内容不因复核变更。

SQLite保存在命名卷records；容器重建保留历史。只在确认不再需要数据时执行 `docker compose down -v` 重建。端口可通过.env中的PORT调整。本地也可 `pip install -r requirements.txt` 后 `python -m app.main`。

## 定义与限制

详见docs/DATA-DICTIONARY.md、docs/DEPTH.md。单文件最大5MB/一万行，本工具按确定性文件离线复算，不查询外部业务系统。源码位于app，测试位于tests，样例位于sample_data。
